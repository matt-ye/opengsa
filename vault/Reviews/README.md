# 人工補充與隱私

此資料夾放人工探索、疑點與承辦回覆；產生器不會寫入或清除這裡的檔案。除了本說明，資料夾內容預設不進 Git，也沒有啟用雲端同步。

建議一件疑點一份筆記，從下方格式開始，把 `related` 寫成實際的方案／來源筆記連結。

```yaml
---
entity_type: review_note
status: open
related: "[[Generated/Programs/faos-student-conference]]"
source_revision: "請填當次來源版本"
---
```

## 內容怎麼回到資料主檔

1. 記錄疑點、適用單位、日期及對應來源版本；只對確定的欄位提出修正。
2. 如果有可公開依據，透過資料 PR 將結論與證據加入 JSON，仍須檢查來源版本。
3. 筆記或 checkbox 不會直接變成獎學金資格核准，也不自動修改網站。

請保留私人通信、學生資料與聯絡人私密資訊在本地人工區。雲端同步若日後啟用，需另外決定哪些人工筆記可上傳；Git ignore 不能代替雲端服務的排除設定。
