# 受阻來源與正文清理研究：整合後狀態

本文件整合 [PR #25](https://github.com/matt-ye/opengsa/pull/25) 的研究方向及 [PR #26 補證註記](CRAWLING-EXTRACTION-BEST-PRACTICES.md#pr25)。原研究中的未附端點實測、零漏失及 Token 節省比例，不作為本分支已完成的驗收。

## 存取與解析分開

存取層沿用既有 Fetcher 的 URL／主機、robots、登入與請求預算限制。解析層只處理已取得的原文；Defuddle 是正文清理工具，不替代授權、認證、robots 或節流。

本輪實作統一文件區塊：HTML 保留章節、表頭、資料列、來源定位與唯一區塊識別；PDF 保留原文行、頁碼及唯一區塊識別，版面／表格恢復未經確認時明示 `pdf_layout_unverified`。沒有安裝 Defuddle、切換代理或啟用額外來源。

## 受阻來源的處置

| 類型 | 當前處置 | 替代入口啟用前所需證據 |
|---|---|---|
| robots 禁止 | 不請求禁止路徑 | 官方替代父頁、檔案完整 URL、該入口的存取規則、文件版本與雜湊 |
| robots 無法判讀 | 維持保守暫停／人工查核 | 公開 API／下載入口的獨立規則或站方授權 |
| 403／429 | 主機暫停、明確延期 | 站方提供入口、額度政策或恢復狀態，不藉代理輪替重試 |
| 登入限定 | 不帶個人 session 掃描 | 可公開內容及合法公開來源；人工瀏覽不等於授權自動存取 |
| 沒有有效正文 | 保留解析失敗，不直接推定 SPA | 原始回應、selector、iframe／跳轉／格式檢查；必要時評估公開渲染流程 |
| 404／410／逾時 | 分別記錄，逾時不當作撤除 | 官方替代入口、年度及條文版本；常態要點不替代當期徵件 |

全國法規 Open Data、秘書室兼任上限表及企業轉知文件目前仍是替代路徑候選，沒有在本輪宣告自動驗收通過。需補具體 URL、查核時間、回應雜湊、授權／額度及可重現的欄位比對。研究中的未核驗金額不寫入候選。

API 開放授權不代表無頻率限制；不同檔案雜湊不能直接證明條文變更；同一雜湊也不證明授權或最新有效性。詳細官方來源見 [最佳實務查核](CRAWLING-EXTRACTION-BEST-PRACTICES.md)。

## 成本與整合

不擴張目前來源，不啟用付費或排程模型，不保存原始 HTML／PDF。局部重萃也須重新經過來源限制與版本檢查；來源受阻時不從短摘錄／雜湊推測完整內容。

目前程式與操作見 [文件準備與彈性重萃](PREPARED-EXTRACTION.md)。
