> **文件狀態**：初版盤查彙整（Draft / 待審核）  
> **建立日期**：2026-10-30  
> **調查範疇**：全台各縣市政府青年/勞工局處、中央部會、國際科技企業、非營利組織（NPO/NGO）  
> **核心用途**：作為 OpenGSA 擴大收錄「AI 工具訂閱補助、學術算力點數、考照培訓實質補貼」之來源基線資料。

## 壹、調查背景與問題意識

隨著生成式 AI（Generative AI）深度融入學術研究、程式開發與職場實務，AI 工具（如 ChatGPT Plus、Claude Pro、GitHub Copilot、Midjourney 等）的訂閱費用已成為青年與學生日常重要的數位學習成本。

目前全台灣已有地方政府（以**臺北市政府青年局**為首創，隨後**新竹市政府**跟進）率先推出**「針對個人購買 AI 軟體訂閱費用實報實銷」**的實質現金補助政策；同時，中央部會（如**勞動部**）亦首度將 AI 工具訂閱納入培力補助額度中；各大國際科技企業與非營利組織則多提供**「學生專屬免費訂閱授權」**或**「雲端算力點數補助」**。

為協助青年與學生完整掌握各方資源，本文件針對各方案之**「主辦單位」、「補助額度／內容」、「適用工具」、「申請方式（紙本 vs. 電子）」與「效期狀態」**進行全盤梳理。

## 貳、申請途徑差異化分析（紙本 vs. 電子申辦）

在盤查過程中，我們發現這類新興補助方案在「申辦流程與遞件方式」存在顯著差異，未來納入 OpenGSA 正式資料集時，強烈建議作為固定屬性特別標註：

1. **紙本郵寄／親送（Paper / Mail）**：
   * **代表案例**：臺北市政府青年局。
   * **特點與痛點**：申請人需自行列印申請書表，附上身分證正反面影本、在學證明影本、官方原始發票／外幣結算單據、存摺封面影本，掛號郵寄或親送主管機關。對學生而言準備實體紙本單據手續較為繁瑣，審核期約需數週。
2. **全電子／數位線上申辦（Electronic Portal）**：
   * **代表案例**：新竹市政府（新竹市數位申辦平台）、勞動部（台灣就業通）。
   * **特點**：全程於網頁系統填表，直接拍照／上傳電子 PDF 憑證與發票截圖，流程直覺快速。
3. **校園信箱／身分即時直通（SSO / .edu / SheerID）**：
   * **代表案例**：GitHub Student Developer Pack、Google、AWS Educate。
   * **特點**：以學校 `.edu.tw` 信箱完成驗證或透過國際學生身分認證服務（如 SheerID）上傳學生證，免信用卡、審核通過後即刻在軟體帳號中解鎖專業版權益。

## 肆、各方案細部規則與限制條款（申請避坑指引）

### 1. 地方政府現金實報實銷方案（臺北市、新竹市）之共通重要限制
* **排除中國大陸及港澳開發之工具軟體**：
  主管機關簡章均明文規定排除中國大陸開發之應用（例如：美圖秀秀、CapCut／剪映、Kling、Wink 等），即使具備 AI 功能亦一律不得核銷。
* **僅限官方網站直接訂閱個人版**：
  * **不得使用代購或合租平台**：如透過第三方集合租用網站（GoingBus、Poe 集合帳號等）購買者不予核銷，必須在官方網站以個人名義直接刷卡訂閱。
  * **排除多人共用／企業版／家庭版**：訂閱方案必須為個人使用（Personal / Individual），若收據載明為 Enterprise、Team 或 Family 則視為不合規。
  * **不補助預付儲值點數（API Token）**：地方政府目前僅補助「定額定期租賃（訂閱費）」，按實際使用量扣點（Pay-as-you-go API Token）不在地方現金核銷範圍。

### 2. 學生信箱直接開通方案之高性價比優勢
* 建議在校大專與碩博士生優先啟動 **GitHub Student Developer Pack**：
  只要有 `.edu.tw` 信箱，即可免費享有原價每月 10 美元（一年約 3,800 元新台幣）的 **GitHub Copilot**，不需經過地方政府繁瑣的單據核銷與設籍限制，亦不佔用每年補助額度。

## 伍、OpenGSA 專案後續資料模型整合建議

若未來規劃將「AI 工具補助／算力資源」正式收錄至 OpenGSA 搜尋與甘特圖中，建議架構團隊考量以下資料契約設計：

1. **擴充 `resource_kind`**：
   現行包含 `scholarship`、`fellowship`、`subsidy` 等，可擴充 `tool_subscription`（工具訂閱補助）或 `compute_resource`（算力點數）。
2. **新增 `application_method` 屬性**：
   ```json
   "application_method": {
     "mode": "paper" | "electronic" | "instant_sso" | "hybrid",
     "note": "需掛號郵寄紙本至青年局，含實體發票憑證"
   }
   ```
   在卡片視圖與甘特圖 Drawer 顯示醒目標籤（如 `[紙本郵寄]`、`[線上申辦]`、`[學生證直通]`），協助學生預先評估作業成本。
3. **時序與甘特圖對齊**：
   工具補助多採「購買後 N 個月內提出」或「特定年度視窗（如 8/1～10/31 訂閱、11/10 截止）」，可對齊既有的 `steps` 與提醒帶（Notice Window）視覺邏輯。
