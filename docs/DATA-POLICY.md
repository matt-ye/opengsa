# 資料、隱私與覆核政策

1. **可追溯**：影響資格、金額、期限、兼領、返還或救濟的資訊，須定位至適用年度官方辦法、公告或附件；搜尋摘要只供發現線索。
2. **保留未知**：未提及限制不等於不限；連結失效不等於停辦；公布不等於生效。
3. **分清角色**：主辦、資助、轉知、承辦、收件及審查單位分開；申請、受益、受獎與受款主體也分開。
4. **獨立覆核**：重大欄位由非原編輯者覆核，否則保持草稿／待確認；自動更新僅產生候選差異。
5. **版本清楚**：制度、年度／梯次機會與校內程序分開；保存原文日期、時區、粒度、有效期間與核對日期。
6. **存取與授權**：先檢查條款及 robots；不繞過登入或封鎖，不把可登入閱讀視為可公開全文。只轉載有依據的內容，保留第三方授權與署名。
7. **最少個資**：公開 repo 不放真實 Profile、學號、證明、薪資單、帳號、本機路徑、私人往來或登入資料；測試使用合成資料。
8. **更正**：公開 issue 可提供資料 ID、欄位及公開來源；個案爭議或敏感證據不可張貼。暫無安全接收私人附件的服務。

目前文件中的來源清單是候選台帳，並非完整現行獎助資料庫；截至日期、資格及金額需逐案重查。
