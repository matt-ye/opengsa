5份同URL且原始內容雜湊完全相同的已讀文件，重新綁定到本次候選版本；保留來源、單位、梯次及年度。4份沒有相同內容證明的已讀文件撤下舊事件／相關規則，等待重核；包含原先千里馬116年臺大校內截止規則，不能沿用為本批學生期限。

候選快照只有版本中繼資料，不能蓋掉同URL真正讀取的資訊鏈；更新快照時清除其中事件並保留快照屬性。候選的暫定方案key與資訊鏈別名尚未合併時，只允許同URL、同候選revision、單一方案的已讀文件提供自身日期，不借用其他卡片的日期。年度／範圍／梯次仍分列，沒有可用資料就留未知，不補估計起日。

較舊的匯入檔不會把整批`as_of`回推；每筆來源仍保留各自查核時間。提案必須通過完整候選／資訊鏈驗證，舊來源版本的核准不能繼承。原型預覽的草稿狀態不改正式`pilot.json`。


請使用新的輸出目錄，保留既有人工處置與產物。前者包含未發布卡片／工作台，後者只有公開站成品。第一頁博士身分篩選保留未知時為63筆（16筆符合已知篩選、47筆可能相關）；關閉未知後16筆，第二、三頁同步。這是篩選結果，不代表16筆資格符合或仍在受理。

## 驗收與後續

本分支213項Python、46項Node測試、`check_data.py`、掃描設定檢查、公開站及工作台建置均通過。Chrome確認64筆載入、博士／未知篩選、第二三頁同步與重設，沒有瀏覽器程式錯誤；這些檢查不替代對來源正文的人工判斷。

本輪來源總成本912次HTTP、模型0；建卡、預覽及測試沒有新增來源GET。掃描台帳61個profile，原13個維持啟用，新加入的全停用；只是可追溯的候選來源，沒有擴大週期排程。正式pilot維持10筆draft、真人處置台帳空、PR34原樣保留，Obsidian不回到主流程。

先審來源PR37，再審本建卡資料PR；是否合併／發布由使用者確認。111個外部受限來源仍需官方替代URL、授權或格式支援；另92個名稱／類型線索仍待後續探索，這些都不算正文已驗證。後續優先做58組方案別名、年度／梯次整理及高價值缺漏補鏈，再逐批核可啟用來源，不重新抓取全部來源以湊完整率。
