## 建議分工

| 原控制／資訊 | 建議位置與整併方式 |
|---|---|
| 來源筆數、甘特圖／清單切換 | 同一張圖表卡片的標題列，筆數緊鄰標題 |
| 用途、來源、學位、年級、兼領、清寒、未知條件 | 左欄「篩選條件」，只決定顯示哪些項目 |
| 已選筆數、勾選結果、清除及第二／三頁入口 | 左欄「我的選項」，管理操作可收合，取消橫跨圖表上方的選取狀態列 |
| 參考年度、時間範圍、往年底帶 | A：放圖表標題下的工具列；B：左欄獨立「時間檢視設定」，避免混成資格條件 |
| 前後30天、回到今天 | 與上述時間控制同區，合成一組按鈕；今天日期只在軸上標一次 |
| 跳至申請／參考時段 | 合併進「涵蓋所有已知日期」操作，選取時同時重設平移並帶到可讀時段；正式套用時需保留對未知日期的處理 |
| 日期範圍、臺北時間 | 工具列下方一行次要文字，不再另做區塊 |
| 圖例、全局閱讀說明 | 圖表卡片內的原生 details，預設收合；展開為白底 grid，每格固定圖示寬度＋文字 |
| 系所適用範圍 | 各獎項旁保留範例單位；圖下保留一行公告優先原則，不在頂部重複長段說明 |

## A／B 取捨

- **A（推薦）**：資格篩選留左欄，時間控制靠近圖表。桌面可以直接調時間；手機資格篩選收起後，時間控制仍在圖表旁。保留年度及時間範圍的可見標籤。
- **B**：把時間設定放到左欄下方，圖表上端更短；但左欄變長，手機操作時間設定後須移動到圖表查看。不能因收合資格篩選而同時隱藏時間設定。

圖例固定圖示欄寬28px、icon置中，文字左對齊；桌面3欄、較窄2欄、小手機1欄。保留文字說明，不能只靠顏色辨識。展開過長時圖例區可捲動，收合標題保持可見。

## mock 可試用範圍

可切換 A／B、展開圖例、切甘特圖／清單、搜尋與篩選、批次／逐項勾選、切年度／範圍、平移、開關歷史底帶。第二／三頁按鈕僅顯示入口意圖，不導向正式網站，也不傳入合成資料。年份切換僅為排版示意，沒有真實歷史推估。

## A版套用驗收條件

1. 既有19筆／13組、未知條件分區及選取跨頁共用保持正確；調時間不改資格或刪除選項。
2. 第一頁仍預設甘特圖；保留圖內雙向捲動、標題與日期軸／左欄固定、今日線及歷史底帶區別。
3. 前後30天、回今天及涵蓋全部日期能配合篩選重新計算，沒有兩個不同步的控制。
4. 圖例預設收合、白底格線對齊、鍵盤可開關；320px無整頁水平溢出，移動圖表不擋住操作。
5. API、排程、正式資料／覆核與部署邊界不變。本輪僅套用已核可的A配置，不合併PR31或部署。

## A版共用前端實作
