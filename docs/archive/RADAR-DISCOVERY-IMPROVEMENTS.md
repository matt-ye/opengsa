## 已改善

- 新增「研究工具／AI／算力」快捷入口，套用`research_tools`分類，目前10筆。沿用共用篩選狀態，不清除搜尋、受理條件或未知設定，第二三頁同步。
- 「呈現方式」收進預設收合的「進階檢視：文件與方案」。仍預設64份文件；方案模式58組，沒有冒稱已完成全語意去重。代表文件優先有明確年度的公告，再比較年度，民國／西元先換到同一尺度，同順位穩定排序；不跨文件拼接資格與日期。
- 舊「資助來源」明確改為「方案來源」。有可顯示的資助單位文字時優先依該文字分類，否則使用方案名稱明載的單位；不由轉知網站或網域推定出資。多類單位有歧義就留未知，分類依據顯示於第二頁。
- 原先顯示層主要靠已知方案key，目前56筆可辨識方案來源、8筆待查：政府28、學校13、企業8、基金會／學會4、研究法人3。分類定義已明確化，這不是正確率，也不代表新增39筆已核定的經費來源事實。
- 通用時間補漏獨立於資格摘要是否已辨識；補認「申請時間／時程／收件期間」，支援星期括號、同段共享年份及明載結束時刻。倒置區間不填，民國116年度補助與115年申請不再互相污染年份檢核。

## 操作與邊界

```powershell
# 一次最多8個已在候選池且曾可讀的來源；輸出限新的work目錄。
python scripts/refresh_radar_subset.py --source-id discovery-r139 --output work/radar-refresh-new
# 同一輪後續微步驟務必填入已消耗的HTTP（含診斷／robots），合計不能超過20。
python scripts/refresh_radar_subset.py --source-id discovery-r140 --prior-requests 2 --previous-output work/radar-refresh-new --output work/radar-refresh-followup
```

以上只產生待審候選、含參考事件的JSON／patch與離線預覽，不自動改checkout或核准。匯入需在獨立分支驗證；原始485來源檢核與`card-import-summary.json`是歷史快照，不回寫成這次萃取結果。新版來源取代舊版本後，測試依URL覆蓋與版本時間檢查，不要求歷史候選ID永遠存在。
