# 原始來源逐項檢核與建卡交付

更新：2026-11-02（臺北）。使用者要求繼續檢核全部原始來源，完成後另開萃取／建卡資料PR；本文件接續[第一輪](SOURCE-EXPANSION-RUN.md)，不把當時「有處置紀錄」當作完整內容檢核。

## 結果與範圍

**485個原始URL均完成逐項盤查結論；不是所有來源的正文都已驗證。** 367個範圍內來源中，256個已取得可讀文件／入口，111個未取得可用正文。H13海外占位、X105參考／非候選仍依核可範圍不擴爬。189個名稱／類型線索不是485個URL的另一套內容驗收，尚未完成名稱的全網探索。

- `classification_review_complete=true`表示該URL已判斷去向；受阻仍保持`content_verified=false`，不是將阻擋解除或塗綠。

## 這輪改善

1. 有界的原始來源檢核器：每筆保留來源ID、查核深度、正文可讀性、格式、定位／雜湊、原頁附件標籤與可建卡狀態。重讀使用同一份整輪及主批記帳，不清零逃過上限。
2. 正文選擇略過空article，保留有文字的main／正文。公開文章與登入小工具分開：只有匿名回應確實提供、且在登入容器外的正文才讀取；不登入、不填表。
3. 通用標題與文章標題分開，尤其電信所舊表格的「公告標題／主旨」鍵值。已對6個原始電信所來源重新驗證，年度、資格及日期仍逐欄查證，不把附件CV範例當主標題。
4. 課程、工具訂閱與地方AI現金補助分流；地方一般／加額分支檢核只對兩個已登錄地方方案生效，不套給AWS、Google、GitHub等資源。
5. 通用金額支援阿拉伯數字與萬／千混合，最高與最低分開；後一句的每月津貼不會把前一句的學費上限變成月給付。
6. 特定日期／金額無法獨立檢核時，僅將該欄位或給付投影降為未知，再重新執行獨立檢核與受理狀態計算。其他錯誤繼續阻擋，不藉此放行整筆不可信資料。
7. 通用候選的申請人、受益者與學校資格未明時保持unknown；不因來源網址、分類或本網站服務學生就預設有資格。萃取器現為`extractor-1.6.0`，舊快照仍保留各自版本。
8. 原頁標籤＋完全一致的檔案raw hash可辨識文件副本；不重複建卡、不因相似檔名或同基金會就合併。對新候選的時間版本綁定也只在同URL、相同原始bytes與對應revision皆具證據時保留舊日期；缺少raw hash仍先撤下舊規則。

原始256個可讀來源仍含入口、附件、制度、教師／機構參考或尚未識別唯一資助名稱的文件。這些有資訊鏈價值，但不硬轉學生卡片。可建卡數量以JSON摘要的57個URL為準。

## 成本與限制

程式HTTP累計912次：上一輪634次＋本輪278次，包含robots、轉址、重讀、標題診斷及重試。B1 188、B2 156、B3 199、B4 26、B5 73、B6 155、B7 67、B8 44；加B0 4次合計912。每主批不超過200，整輪不超過1200，微批20HTTP／180秒／12份文件，同站至少3秒。沒有因B3接近上限改記到其他批次。先前8次搜尋工具／24組查詢仍另列；本輪沒有新增外部模型、付費服務或來源API。

原始HTML／PDF／Office全文只在記憶體；repo存結構化結果、短證據／雜湊及公開連結。`hash_only`沒有外送API或保存引文。PR34、C槽舊專案、其他PR及人工台帳不動。

剩餘111個來源的正文不可取得，是來源或工具能力限制；本輪已逐筆說明下一個可行動作，沒有宣稱解決這些外部條件。若日後取得授權、可讀格式或正式替代URL，再依來源ID重查，不能直接將本批結論改成內容通過。

## 操作

```powershell
# 網路操作：沿用本輪記帳，所有原始URL均須留結論。
python scripts/verify_original_sources.py
# 僅在明確調整解析方法後重查指定來源；受限與預算界線不變。
python scripts/verify_original_sources.py --retry-source R136
# 離線：完整覆蓋驗證、排除誤收與重複，產出逐項報告。
python scripts/close_source_verification.py
```

上述預設讀取忽略的`work/expansion/`狀態；不是可從空狀態立即重現原始網站歷史內容的資料備份。新的完整網路輪次須使用新的台帳與核可預算，程式／盤點指紋變更不能無聲沿用舊結果。已存JSON可離線檢核完整覆蓋、界線、成本與建卡資格，無需重抓來源。

本批候選維持pending；程式／來源盤查PR與下一個建卡資料PR分開，均不自動合併或部署。
