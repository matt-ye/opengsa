# 既有候選穩定化（2026-10-31）

使用者核可先修正本批、穩定後再擴張。本輪不新增來源、不發布資料；PR #24 延續待審。正式 pilot 仍 10 筆，人工覆核台帳仍空。

## 結果

既有 13 個來源、17 份文件、19 筆文件候選重新取得並核對原版本，來源語意版本全部相符。當前為 **8 筆自動檢核通過、11 筆有缺漏、0 筆人工核准、0 筆自動檢核失敗**。相較初次盤查的 12／7，本次將尚未實際萃取的資格、給付身分及完整度問題明確列為缺漏，沒有降低標準以維持通過率。

萃取器與檢核器更新為 1.3.0。最後全批重跑與 N/A 規則追驗合計 38 次受限 HTTP，分批仍維持 20 次／180 秒及同主機 3 秒間隔；此數字不包含前期診斷、較早重跑及官方網頁查詢。模型呼叫 0 次，不保存原始 HTML／PDF、不改來源存取限制。

## 修正與檢核

| 問題 | 修正與目前處置 |
|---|---|
| 千里馬年額與公式重複計算 | 只保留年補助計算基準；同段公式不另建一次給付。檢核會阻擋同證據、同身分及同金額的重複列項；實領依核定研究日數計算 |
| TA 每月範圍寫成總額、漏掉身分 | 月／年摘要優先保留週期。處理 PDF 換行及 ASCII 分號，保留博士、碩士、學士三個級距；金額與對象不能任意拼接 |
| PDF 同頁借用其他行的單位或資格 | 金額檢核依來源定位與確切文字雜湊取證；不將整頁文字視為每個給付列項的證據 |
| 研究人力局部限制變成全局條件 | 專任學歷級別與學生兼任給付分列；移除由臨時工／專任條款推導的全局非在職限制，保留各角色逐條覆核 |
| 電資院方案配對到醫學院學生 | 有原文的院別限制保存在 institution_scope，轉為網站資料時繼續保留；P1 醫學院測試案例判為學院不符。其餘資格與金額仍待補證 |
| 制度文件顯示不存在的申請窗口 | 僅對有文件依據、沒有受理窗口線索的聘任制度參考文件標文件層級 N/A。實際招募窗口另查；有截止線索但日期未解析者維持未知，不代表免申請或自動錄取 |
| 缺漏未出現在審查介面 | 將 coverage 警告納入來源缺漏，阻擋提出核准意向；保留個人資料與經費狀態的獨立分類 |
| 同方案多文件、覆寫風險 | 審查台依 13 組方案列相關文件，19 筆仍分別綁定版本與內容指紋。直接資料匯出也阻擋同一 opportunity 多份文件互相覆寫 |

官方依據：[博士生赴國外研究要點](https://law.nstc.gov.tw/LawContent.aspx?id=FL039188)、[研究人力約用注意事項](https://law.nstc.gov.tw/LawContent.aspx?id=FL028686)。候選仍為來源摘要與待審資料，不代表適用所有學生的給付承諾。

## 文字審查與文件整併

`build_review_workspace.py` 除原有頁面，新增 `review-text.md`，按 program_key 分組並列給付、來源、檢核與缺漏，方便遠端逐批討論。方案分組只建立文件關聯，不自動將法規、歷史年度與當期公告拼成一份正式申請卡片；年度不明的教育部附件不併入 115 學年度。

第一至三頁目前仍是逐文件候選預覽。正式資料整併須決定適用年度、代表公告及支援條文，重新核對所有重大欄位並取得獨立覆核；本輪沒有自動完成內容整併或發布。
