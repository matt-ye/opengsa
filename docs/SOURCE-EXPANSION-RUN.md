## 這輪修了什麼

1. 有界、可續跑的來源擴展：使用既有Fetcher／IR／萃取與獨立檢核。台帳、程式版本指紋不同不能沿用舊掃描狀態。原URL與實際轉址、原頁觀察連結及台帳脈絡分開保存；原始HTML、PDF、DOCX、ODT僅記憶體，不保存全文檔。
2. DOCX／ODT做有大小上限的ZIP/XML文字準備，拒絕DOCTYPE／ENTITY、不跟外部關係。舊DOC、掃描PDF、版面不明與不支援格式保留原因。這不等同已理解複雜跨頁表格。
3. 收緊候選門檻：首頁、一般獎學金索引、說明會及發放通知保留為鏈文件。集中校準時移除3筆誤收候選；不能把索引上混合年度的日期合成一個申請期。
4. 嘗試從低階文章標題補回網站通用h1；多個可能標題不任選。電信所部分頁面仍只辨識到通用頁名，這些頁面保留來源，不硬造具名卡片。
5. 修正獨立金額檢核：支援小數「萬」及中文大／小寫混合單位，防止`2.5萬`誤匹配`5萬`、小數金額截成整數。鴻海來源在修正後重抓通過，仍因年度等缺口保持`passed_with_gaps`。這是同批校準，不是獨立盲測。
6. 修正通用候選預設值：網站主機與來源類別只作檢索分流，不當成學校資格或學生為正式申請人的證據；未查明者保留unknown。一般基金會獎學金不再預設分流博士研究。pilot草稿契約新增unknown申請角色，使三頁預覽不必偽填學生。
7. 文件可以採比來源台帳更嚴格的hash_only，但不能反向放寬；hash_only仍拒絕摘錄與盤查引文。

## 日期與資訊鏈仍需分開驗收

集中補查留下43項有revision、定位與block hash的時間事實。學生、單位、機構、結果、補件及修法分流；缺年份不補當年；「即日起」須同時引用已識別的公布日才推導起日。年齡、購買／訂閱、給付及聘任期間不當申請期。

這43項**不是43段已確認申請期間**。部分頁面有多個年度、對象或角色，尚待綁定方案／梯次／單位。它們只進資訊鏈樹，不直接進公開甘特圖。既有可追溯的系所範例保留各自範圍；未確定主辦、年度或校內收件程序者不給職治所套用他系期限。

資料提案遇到來源候選revision不同，先撤下11份舊文件上的時間事件及依賴規則，避免新卡片沿用舊版日期；這可能降低部分日期可見度，提案摘要明列。沒有宣稱原文內容一定改變；下一批可比對原始hash後，對確實未變且同範圍的日期重新建立版本綁定。

## 受阻與下一批

- 生輔組、登入／SSO、舊HTTP與人工標記繼續人工；沒有爬取授權，不用Defuddle、替代代理或跨站路徑解鎖。
- 中技社、中信、玉山、台經院、國衛院、部分中研院／基金會入口等有robots無法解析或403處置。精確URL與主機暫停原因以JSON為準；不要把同一主機另一頁可讀當作全站授權。
- 優先修16個必要標記不符、舊轉址與通用文章標題；每種版型先小樣驗證。醫學院優秀著作獎、職治所與國際生入口有搜尋或替代線索，仍須合法取得正文，不能由搜尋摘要補齊。
- 先把人社撰論文、千里馬歷史校內公告及鴻海／元大新候選按方案／年度／適用學校綁定，將有證據的日期逐批接進時間軸；再處理92項名稱待辦。既有新竹年齡基準、教育部附件與院系收件日未明者維持待核。
- 正式匯入27筆仍須獨立資料PR、更新該批數量基準與日期綁定，經使用者按批確認後才部署；本輪程式PR合併不會讓它們自動上架。

## 操作與重現

離線重建提案、工作台及前三頁（輸出目錄須不存在或為空）：

```powershell
python scripts/propose_radar_update.py --candidates data/source-expansion/candidates-2026-11-01.json --config data/source-expansion/profiles-2026-11-01.json --output work/expansion-review
```

開`work/expansion-review/preview/candidate-preview.html`看三頁；`review.html`看逐筆診斷，`summary.json`看整批差異，`data-pr.patch`及`repo/`是可覆核的資料提案。整個過程HTTP／模型0、不修改checkout、不代填核准。未知預設可列為可能相關；取消該選項後只顯示已知條件符合的結果。公開「回報問題」連結仍只預填資料識別與原文，不代送Issue。

來源首輪重跑是**網路操作**，需沿原計畫預算，不能將本輪歷史報告當快取繼續使用新程式：

```powershell
python scripts/expand_sources.py --batch B1 --state work/expansion-next/state.json --output work/expansion-next/report
# 對同一份state依序B2..B8；資料／解析版本變更時使用新state。
```

`refine_source_documents.py --extras <來源清單JSON> --extras-only --refresh`為有界重讀；不解除主機暫停，與主掃描共用整輪／主批記帳。`export_expansion_report.py`可由本輪本機狀態重建壓縮JSON及HTML；大型定位manifest只留在忽略的work狀態，repo只保留document hash／unit count與已用到的證據定位。

週二／五排程不增加來源或頻率，模型仍off；新增的是掃描後的資料提案與離線預覽artifact（14天），Actions權限仍唯讀。維護者取artifact後按批開資料PR；不啟用自動commit、合併或部署。
