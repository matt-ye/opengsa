連線成功、文字可解析、欄位有證據、自動檢核通過及真人核准是不同門檻。**不能宣稱所有網址都已支援自動萃取或所有候選都可申請。** 索引／法規參考的可讀性檢查不等於已完成每個下層方案或完整法律判定。

## 本輪修正

1. **PDF 管線**：primary PDF 可直接掃描；附件候選需精確 URL 白名單及父頁綁定。審查重抓時必須從最新父頁重新發現附件，再遵守 robots 下載；不因 URL 曾列入台帳就直接放行。
2. **附件完整度**：未抓或受限制的必要附件會影響 coverage；實際取得申請附件後才解除對應缺漏，不靠已知檔名假稱成功。
3. **文件分類與年度**：申請 PDF 不是一律 policy_snapshot；教育部申請文件提到「不得兼領國科會」不會產生假的國科會資助分支。博士、遠學及校長獎缺明示年度時不再填固定年度。PDF 相容字及全形字先 NFKC 正規化。
4. **給付證據**：國科會月支最低標題、學歷級別、金額一起取證，檢核不能只看數字存在。給付單位／對象不明的博士申請文件金額保留證據線索與查核待辦，不當作已確認總給付。
5. **覆核安全**：預覽每份文件有獨立 ID；同方案不同文件分列待整併。一次核准多份同一 opportunity 的提案會攔截，防止最後一份覆蓋前面內容。`--source-id` 可分批覆核，請求預算不提高。
6. **來源 URL**：修正 `&LTPno` 被誤當 HTML entity 的問題；百分比編碼及 Unicode 路徑去重。robots 的「路徑禁止」不擴張為整個主機禁止；無法讀取 robots 或 403／429 才暫停主機。補查時仍不取被禁止的路徑。

萃取器／檢核器版本為 1.3.0；候選契約維持向下相容的 1.1.0-candidate，新增選填 parent_url。所有 HTTP 測試使用合成輸入及 mock，沒有合成真人審查紀錄入庫。

## 無法自動處理的來源

| 類型 | 處置 |
|---|---|
| 生輔組 robots 回傳網頁而非規則 | 使用者確認無另行授權，人工查核；不換代理繞過 |
| 公告系統三份彙整 PDF、法務部法規查詢、研發處附件等 robots 禁止 | 保留 URL／原因，既有規劃紀錄不是本輪重抓成功 |
| FAO 登入內容 | 不帶登入 session 掃描；維持人工入口 |
| 台積電 403、工學院 robots 無有效規則、兼任上限表禁止路徑 | 三個 profile 保持停用；不以搜尋結果或轉貼摘要冒充 crawler 驗收 |
| 404／410、動態或沒有有效正文 | 明示狀態，不當作方案不存在；需官方替代入口或明確資料格式再接入 |
| 院系首頁及其他搜尋種子 | 目前完成入口／連結發現層；尚未自動啟用每個下層方案，不捏造資格及日期 |
| 海外學位占位與技術參考 | 沿用已接受的暫緩海外全面檢索範圍；技術文件不轉成獎學金 |

新竹年齡、教育部附件及院系實際收件日已向使用者詢問可公開的補充來源；沒有補證就維持待核。其他來源可繼續獨立審查。

## 操作與成本

```powershell
# 離線全批工作台，0 來源 GET
python scripts/build_review_workspace.py --output work/review-all-new

# 先限定少量來源，再由該工作台下載人工處置意向
python scripts/build_review_workspace.py --source-id nstc-assistant-rule --refresh --output work/review-nstc-new

# 只有實際人工決定後才可匯出提案；不直接發布
python scripts/build_review_workspace.py --source-id nstc-assistant-rule --refresh --decisions work/review-decisions.json --export-draft --output work/review-nstc-final

# 重建 URL 清單但不探測；不會寫正式資料
python scripts/audit_sources.py --output work/source-inventory-new.json
```

每批仍最多 20 次 HTTP、至少 3 秒同主機間隔、180 秒；掃描最多 5 份變更及 24 份待審佇列。這次人工全盤分批驗證，不把數百次檢查改成排程頻率。19 筆是多批次整理的候選，不是放寬單輪待審上限。

紀錄包含 scanner 92 次 HTTP、URL 探測鏈 206 次；兩者分開保留，另有官方查詢及診斷請求，不宣稱是全輪網路流量總數。中斷當下未完成請求可能未入鏈計數。**模型 0 次、無付費 API，排程 model_mode=off。** 僅保留結構化資料、原創待辦、URL 及短證據／雜湊；沒有存放原始 HTML／PDF，沒有新增資料庫、帳號或通知。

本輪待審資料約 268 KB，來源紀錄約 116 KB。驗收包括完整 Python／Node 測試、資料及設定檢查、公開建置、19 筆離線工作台與按來源分批操作；正式發布仍須逐批獨立覆核及資料 PR。
